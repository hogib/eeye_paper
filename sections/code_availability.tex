\section*{Code availability}

Name of the software: electric-eye (programs \eeye{} and \hellion{}). Developer:
H. O\u{g}uz Bolat,
\href{mailto:oguz.bolat@std.yildiz.edu.tr}{\nolinkurl{oguz.bolat@std.yildiz.edu.tr}}.
Program language: C99. Hardware requirements: an x86-64, ARMv7 with
NEON or AArch64 processor;
tested on desktop and laptop computers and, for the ARM builds, under emulation.
Software required: a C99 compiler, GNU make and libjpeg-turbo to
build; FFmpeg at run
time for \hellion{}, except on a vehicle that sends its camera's own
H.264. The source code, its documentation and the release binaries are at
\url{https://github.com/hogib/electric-eye}, and release v0.3.2 is archived
\cite{electriceye}. This description corresponds to commit b7a2e8a,
which follows
v0.3.2 and adds the transport of a camera's own H.264. The comparison of
Section~\ref{sec:res-uieb} was made with the programs in the repository's
\texttt{bench} directory at commit 52cdcbc.
